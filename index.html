Install & troubleshooting

FAQ

Gatekeeper on macOS, Docker and the web ZIP, desktop downloads, updater signatures, and where to get help.

01macOSWhy does macOS block the desktop app, and how do I fix it?

Release builds are ad-hoc signed but not Apple-notarized. After you download the ZIP, Gatekeeper may say the app can’t be opened or is damaged.

In Terminal, clear quarantine yourself or run this release’s fix script:

xattr -cr "/Applications/Data Explorer.app"

# or (per-release script):
curl -fsSL https://github.com/midrissi/4d-dataexplorer/releases/latest/download/fix-macos-quarantine.sh | bash

macOS first-launch guide·ZIP also includes README.html and fix-macos-quarantine.sh

02InstallI prefer Docker or the web ZIP — how do I install those?
  • Web ZIP (4D) — DataExplorer.zip → extract into the database WebFolder so files land in dataexplorer/ → open http://<host>:<port>/dataexplorer/index.html.
  • Docker — pull ghcr.io/midrissi/4d-dataexplorer:latest, set BACKEND_URL to your 4D REST host, open http://localhost:8080/dataexplorer/ (default).

Getting started·Use Run with Docker above for a copy-paste command

03UpdatesDesktop update failed with a signature error — what can I do?

Reinstall — don’t keep retrying the in-app update. Signature failures mean the release signing key no longer matches the public key in your installed build (key rotation or mismatched channel).

  1. Download a fresh installer from GitHub Releases for your platform.
  2. Quit the old app and replace it (macOS: clear quarantine again if needed).
  3. Launch the new build — auto-update should work from that install onward.
04DesktopWhich desktop download should I pick?

Use Download above — it prefers your current platform. On macOS pick Apple Silicon (aarch64) or Intel (x86_64) ZIP; Windows MSI/EXE; Linux AppImage / deb / rpm. Prefer the ZIP app bundle on macOS over DMG for these ad-hoc builds.

All releases & checksums

05ChannelsWhat’s the difference between desktop, Docker, and DataExplorer.zip?
  • Desktop — native Tauri shell with optional auto-update. Standalone app.
  • DataExplorer.zip — unzip into the database WebFolder, then open /dataexplorer/index.html on the 4D web server.
  • Docker — same web UI in a container proxying REST to your 4D host. Demos, CI, or hosts without unpacking into WebFolder.
06ConnectHow do I connect with an access key?

After unzipping into WebFolder, open http://<host>:<port>/dataexplorer/index.html (your 4D web server URL).

If REST authentication is required, enter your access key on the login screen.

Getting started

07TrustIs the macOS build safe if it isn’t notarized?

Builds are ad-hoc code-signed in CI; checksums ship with each release. Without Apple notarization, Gatekeeper is cautious about internet downloads — that warning is expected, not proof of malware. Only clear quarantine for builds from this project’s official Releases.

08SupportWhere can I get help or report a bug?

Support is on GitHub (no Discord). Open an issue, browse the guide, or read release notes for what changed.
