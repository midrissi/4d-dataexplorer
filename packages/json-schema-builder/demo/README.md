# JSON Schema Builder - Demo

Run the demo page to try the schema builder in the browser:

```bash
bun run demo
```

Then open http://localhost:4000/ (or the port Vite prints).

The demo includes:

- A root object schema with two properties (`name`, `count`)
- The **View JSON** plugin tab to see the current schema and `$defs` as JSON
- Toggle **Definitions ($defs)** to add/edit/reuse definitions and convert blocks to references
