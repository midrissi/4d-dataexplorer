macOS desktop first launch ​

Desktop builds from GitHub Releases are ad-hoc signed but not Apple-notarized. After download, macOS Gatekeeper may say the app can’t be opened or is damaged.

Clear the quarantine attribute, then open the app. Prefer Terminal (commands you paste are not blocked the same way as double-clicking a downloaded helper script).

Quarantine fix script (per release) ​

Each GitHub Release publishes its own fix-macos-quarantine.sh (stamped with that version). The same file is inside the macOS ZIP. Use the script that matches the app you downloaded — not an older or newer release’s copy.

Download .sh Source on GitHub

Each GitHub Release ships its own fix-macos-quarantine.sh (also inside the macOS ZIP). Prefer a direct one-liner? xattr -cr "/Applications/Data Explorer.app" — full steps: macOS desktop first launch.

Install with Terminal ​

bash
curl -fsSL https://github.com/midrissi/4d-dataexplorer/releases/latest/download/install-desktop.sh | bash

Windows (PowerShell):

powershell
irm https://github.com/midrissi/4d-dataexplorer/releases/latest/download/install-desktop.ps1 | iex

Or use the Install via Terminal tabs on the docs home Download control (your OS is preselected).

Quarantine fix only ​

bash
curl -fsSL https://github.com/midrissi/4d-dataexplorer/releases/latest/download/fix-macos-quarantine.sh | bash

For a specific tag (example v1.2.3):

bash
curl -fsSL https://github.com/midrissi/4d-dataexplorer/releases/download/v1.2.3/fix-macos-quarantine.sh | bash

The script looks for Data Explorer.app in the current folder, /Applications, ~/Downloads, and ~/Desktop, then runs xattr -cr and opens the app.

Run xattr yourself ​

If the app is already in Applications:

bash
xattr -cr "/Applications/Data Explorer.app" && open "/Applications/Data Explorer.app"

If it is still in the unzipped folder — type cd then a space, drag the folder into Terminal, press Return, then:

bash
xattr -cr "Data Explorer.app" && open "Data Explorer.app"

ZIP contents ​

Each macOS desktop ZIP from CI includes:

  • Data Explorer.app — the application
  • README.html — offline guide (URLs stamped for that release)
  • fix-macos-quarantine.sh — the same per-version script (run via bash, not double-click)

Copy a browser session ​

On the Connection screen, fill the Server URL then use Sign-in on the right of the field. Data Explorer opens /rest/$singleton/CopySession/copySession in a browser (copy the link, or open it in Chrome / Firefox / Safari / Edge). Confirm on the 4D page to send the session cookies back to the app. Named parts.

Install the CopySession shared singleton class in your 4D project (use Download CopySession class from the Sign in menu and drop CopySession.4dm into Project/Sources/Classes/). Edit the trusted URL list at the top of that class if the callback is not localhost.

Optional: keep a one-line datastore wrapper so /rest/$catalog/copySession still works:

4d
exposed onHTTPGet Function copySession($callbackUrl : Text; $state : Text) : 4D.OutgoingMessage
	return cs.CopySession.me.copySession($callbackUrl; $state)

Default trusted callbacks: http://localhost:*, http://127.0.0.1:*, their https variants, and dataexplorer://* (mobile).

Page zoom and links ​

  • Zoom — View menu Zoom In / Out / Reset, or ⌘/Ctrl + + / - / 0. Pinch or ⌘/Ctrl + scroll zooms only while the gesture started with ⌘ or Ctrl (trackpad inertia after you release the modifier does not keep zooming).
  • External links — https, http, and mailto links open in the system browser (WebView ignores target="_blank"). Rebuild after permission changes so the opener allowlist applies.
