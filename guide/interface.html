Interface overview ​

The workspace has six areas: Header, Sidebar, Tab bar, Editor, optional Console dock, and Status bar. Named parts for each editor live on Anatomy.

Resizable panels ​

Both the sidebar and the entity list / viewer split are resizable:

  • Sidebar — drag the right edge to change width (325-450 px). Double-click the resize handle to reset. Collapse to a 52 px icon rail from the Status bar toggle or ⌘ B.
  • Entity list — drag the handle between the list and entity viewer (25-70% of the row). Double-click the handle to restore the default 40% split.
  • Console dock — when open, drag the top edge of the bottom panel (120 px-50% of the window). Double-click to reset. See Console. The same dock hosts the ORDA Terminal via a tab strip.

Panel widths are saved per profile and per database.

The Flows control on the Status bar opens the Flows editor (a full tab, not the Console dock).
