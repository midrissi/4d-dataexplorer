Trusted folders ​

Desktop and mobile only. Allowlist local folders so HTTP Client, entity image/blob fields, and Anonymize can feed 4D $upload with a random or specific file. This is the Files editor (named parts).

Open it from the Status bar Files control, the command palette (Trusted folders), or the mobile Tools menu.

Folders are stored on this device (alias + absolute path). They are not part of profile export.

Paths must live under Home, Desktop, Documents, or Downloads (the native filesystem scope). Removing a folder from the list asks for confirmation and only drops the alias — files on disk are not deleted.

Template syntax ​

$files is file-valued. It is resolved only when sending a binary / form-data body or uploading an image/blob — not as a string in URLs or JSON.

text
{{$files.photos}}
{{$files.photos | ext:jpg,png,webp}}
{{$files.photos | recursive:false}}
{{$files.photos/cat.jpg}}
{{$files.photos/sub/cat.jpg}}
{{$files.photos/**/*.png}}
{{$files.photos/Black/*.png}}
  • {{$files.alias}} — random file from that folder
  • {{$files.alias/relative/path.jpg}} — a specific file (use / because filenames contain dots)
  • {{$files.alias/**/*.png}} — random file matching a glob (* one segment, ** any depth)
  • | ext: — restrict a random pick by extension
  • | recursive:false — only the folder’s top level

Relative paths cannot contain .. or start with an absolute drive / root.

File manager ​

The editor has a folder list, an explorer, and a preview pane (wide screens). Sidebar width, preview width, list vs icons, the selected folder, expanded tree paths, and the current file persist on this device.

Flows Open / Save to trusted folder reuse the same picker without the preview pane, with a file-type menu (JSON or All files). Other pickers can keep preview and pass their own extensions.

  • List — tree of folders and files
  • Icons — folder contents as a virtualized grid (large folders stay responsive); double-click a folder to open it; use the breadcrumbs to go up. Thumbnails are a fixed height so rows do not overlap. The file type is a muted badge under the name (not overlaid on the image). Long names wrap without splitting the extension
  • Preview — image thumbnail when possible, plus copy actions for $files templates (specific file, type glob, this-folder glob, random)

Copy buttons use click-to-copy: the tooltip reads Click to copy, then Copied! after a click.

HTTP Client ​

For POST /rest/$upload?$rawPict=true (images) or ?$binary=true (other files), set the body to Binary and either pick a file or enter a $files template. Form-data file rows accept the same template.

Saved requests keep the template text so each send can pick a new random file.

Entity fields and Anonymize ​

While editing an image or blob attribute, From trusted folder opens the explorer (specific file or random from the folder) and uploads via $upload.

In Anonymize, set an image field’s template to {{$files.photos}} (or a specific path / glob). The run loads the local file and uploads it instead of fetching a remote Faker image URL.

Flows File and CSV import blocks also read trusted-folder aliases (desktop / mobile). The Flows library can open and save a flow JSON as a live file inside a trusted folder; later edits auto-save to that file.
