Data Explorer — User Documentation ​

Data Explorer (4D REST Explorer) is a web, desktop, and mobile application for browsing, querying, and managing data in a 4D database through the REST API. It provides a tabbed interface, visual structure graph, query builder, selection tools (analyze / export / import / anonymize), Method Executor, HTTP Client, REST Export (Collection / OpenAPI), console and ORDA terminal, Flows, AI assistant and dataclass AI actions, and rich customization options.
