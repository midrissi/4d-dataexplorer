# JSON Schema Builder

Build and edit JSON schemas visually.

![JSON Schema Builder](/screenshots/17-schema-builder.png)

Open from **Tools** (footer wrench menu) or the command palette.

- Expand/collapse nested objects
- Add properties with types, formats, and constraints
- Monaco editor with completion (respects **Code editor** settings)
- **Copy schema** — copy the current schema JSON to the clipboard
- **Test schema** — validate sample JSON against the schema
