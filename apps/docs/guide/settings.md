# Settings & appearance

Open **Settings** from the footer gear icon or the command palette.

![Settings overview](/screenshots/09-settings-general.png)

### General

- **Read-only mode** default
- **Default list view** — Cards or Table
- **Default entity view** — Tree, Form, or JSON
- **Default edit mode** — Form or JSON when editing
- **Page size** — rows per page for new dataclass tabs
- **Sidebar view** — Cards, Tables, or Icons

### Appearance

Data Explorer supports multiple color themes and light/dark mode.

![Appearance settings — Tangerine dark theme](/screenshots/10-settings-appearance.png)

Available themes: **Slate**, **Tangerine**, **Violet Bloom**, **Graphite**, **Aurora**, and **Vercel**.

Switch theme quickly from the footer palette icon:

![Theme selector](/screenshots/12-theme-selector.png)

Toggle light/dark with the sun/moon icon or `⇧ ⌘ D`.

### Dataclass appearance

Assign an icon and color to each dataclass for the sidebar, tabs, and Home screen.

![Dataclass appearance with generated icons](/screenshots/00-dataclass-appearance.png)

1. Open **Settings** → **Dataclass Appearance**
2. Click **Randomize (N)** to assign random icons/colors to dataclasses without customization
3. Click **Reset All** to clear customizations
4. Click **Edit** on a row to customize a single dataclass

### Code editor

Configure Monaco editor preferences (font size, word wrap, toolbar) with a live JSON preview. Applies to entity forms, schema builder, and JSON views.

### Keyboard shortcuts

View and customize all shortcuts in Settings, or open the quick reference modal from the footer.

![Keyboard shortcuts modal](/screenshots/11-keyboard-shortcuts.png)

Preset layouts: **Default**, **VS Code-like**, **Vim-like**, **Emacs-like**. Record custom chords from the shortcut editor. Enable or disable individual shortcuts and whole categories.

### AI Assistant tools

Enable or disable **tool namespaces** and individual tools the assistant can call (query, navigation, UI control, metadata, etc.).

### Reset all settings

**Reset all settings** (General section) restores defaults for the current profile. Dataclass appearance and per-database data are not removed.
