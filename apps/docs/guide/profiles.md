# Profiles & import/export

Profiles store independent preferences: theme, shortcuts, sidebar width, panel sizes, recent commands, code editor settings, and language.

From **Settings → Profiles**:

- Create, rename, duplicate, and delete profiles
- Customize profile icon and color (footer quick switch when multiple profiles exist)
- **Export** all settings or selected profiles to JSON
- **Import** settings from a file with per-profile overwrite control

Each database (**BASEID**) keeps its own tabs, dataclass customizations, and graph viewport — these are stored separately from profile preferences.
