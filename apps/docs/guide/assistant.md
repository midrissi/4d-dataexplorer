# AI assistant

The AI assistant panel helps you query data, navigate the UI, and run commands using natural language. For dataclass-scoped generate / ask workflows that run in the background, see [AI actions & tasks](/guide/ai-actions).

![Assistant panel](/screenshots/16-assistant-panel.png)

Open with the footer sparkles icon or `⌘ ⇧ A`.

## Capabilities

- Query dataclasses and entities through REST
- Open tabs, run command palette actions, toggle settings
- Interactive prompts (confirmation and choices) when a tool needs your input
- Render **Mermaid** diagrams in responses
- **Fullscreen** mode (press `Esc` to exit)
- **Copy trace** from the activity panel

## Configuration

1. Configure an LLM provider in the assistant panel (**Configure**)
2. Enable desired tools in **Settings → AI Assistant Tools**
3. Document your schema in the [Assistant Metadata Editor](/guide/metadata-editor) for better answers
