# Sidebar & dataclasses

The left sidebar lists every dataclass exposed by the REST API.

- **Sidebar search** — focus the search field with the chord `⌘ K` then `⌘ P` (search dataclasses), or click the field and type to filter by name
- **View modes** — cards, table, or icon-only list (configurable in Settings → **Sidebar view**)
- **Collapse** — use the footer chevron to shrink the sidebar to icons only

![Collapsed sidebar](/screenshots/14-sidebar-collapsed.png)

Each dataclass can have a custom **icon** and **color** (see [Dataclass appearance](/guide/settings#dataclass-appearance)). In the screenshots below, icons were generated with **Randomize** in Settings using the **Tangerine** dark theme.
