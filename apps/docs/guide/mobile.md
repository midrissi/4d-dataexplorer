# Mobile apps

Data Explorer is also available as native **iOS** and **Android** apps (Tauri). You connect to a 4D REST server from a connection screen; browsing, query, console, terminal, and HTTP Client use the same core UI as the web app, adapted for touch.

### Highlights

- Connection profiles with optional TLS skip for local/dev servers
- Safe-area aware chrome; bottom dock (Console / Terminal) as a full-screen overlay
- Share / save downloads via the system share sheet (iOS) or Downloads (Android)
- Touch-sized controls in the ORDA Terminal composer (REPL / Code, Run, snippet tabs)

Desktop and web docs in this guide apply unless noted as desktop-only (window menus, auto-updater) or web-only (Docker hosting).
