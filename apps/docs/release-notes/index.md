# Release notes

Data Explorer release notes are available in three languages. In the app, click the version label in the footer to open them in a dedicated tab.

![Release notes](/screenshots/13-release-notes.png)

## Choose a language

| Language | Link |
|----------|------|
| English | [Release notes (EN)](/release-notes/en) |
| Français | [Notes de version (FR)](/release-notes/fr) |
| Español | [Notas de la versión (ES)](/release-notes/es) |

Release notes support search, a version timeline, and localized content.
