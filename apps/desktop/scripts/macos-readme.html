First launch on macOS

This build is ad-hoc signed but not Apple-notarized, so macOS may block it. Fix it in Terminal — paste a one-liner, don’t double-click helper scripts.

Quick fix

Open Terminal, cd into this unzipped folder (type cd then a space, drag the folder in, press Return), then paste:

From this folder (no internet)

bash "./fix-macos-quarantine.sh"

Or from the internet

curl -fsSL https://github.com/midrissi/4d-dataexplorer/releases/latest/download/fix-macos-quarantine.sh | bash

Fresh install (download + install + open)

curl -fsSL https://github.com/midrissi/4d-dataexplorer/releases/latest/download/install-desktop.sh | bash

Manual alternative:

xattr -cr "Data Explorer.app" && open "Data Explorer.app"

Or after moving to Applications: xattr -cr "/Applications/Data Explorer.app"

More help

Why does macOS block this?

Gatekeeper expects Developer ID signing + notarization. These CI builds are ad-hoc signed only, so downloads get a com.apple.quarantine flag. xattr -cr clears it for this copy — it does not disable Gatekeeper.

Right-click → Open

You can also right-click the app → Open → confirm. If macOS still says the app is damaged, use the Terminal one-liner above.

Script can’t find the app

cd into this folder, move the app to /Applications, or pass a path: 

curl -fsSL https://github.com/midrissi/4d-dataexplorer/releases/latest/download/fix-macos-quarantine.sh | bash -s -- "/path/to/Data Explorer.app"
Docker or web ZIP instead?

docker pull ghcr.io/midrissi/4d-dataexplorer:latest or install DataExplorer.zip into 4D Resources/WEBJS/. See Getting started.
